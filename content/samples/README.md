# Sample lessons for the import screen

`local_context_lesson.csv` is a Grade 1 numeracy lesson written by the team in simple Hindi
with things a child in a Jharkhand village sees every day: sal leaves and leaf bowls (दोना),
mahua flowers, goats in the courtyard, eggs from the weekly market (हाट). It is **not** built
in: a teacher imports it (पाठ → पाठ जोड़ें → upload the file) and the app makes the Santali,
the audio, the worksheet and the flashcards, all marked as awaiting native review.

It shows the intended way to localise content: the teacher or the community writes the
examples in Hindi, the app translates them, a native speaker reviews them. The team has no
native speaker, so no Santali cultural content is written here.
